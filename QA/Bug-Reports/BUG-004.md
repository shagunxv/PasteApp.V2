# BUG-004: Empty Registration Fields Cause Server Error

- **Module:** Authentication – Registration
- **Endpoint:** POST /api/register
- **Severity:** High
- **Priority:** High
- **Input:** Empty name, email and password.
- **Expected:** 400 Bad Request with required-field validation messages.
- **Actual:** 500 Internal Server Error.
- **Status:** Open

**Impact:** Users receive a server error instead of meaningful validation feedback when submitting an empty registration form.
