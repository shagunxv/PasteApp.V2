# BUG-006: Weak Password Causes Server Error

- **Module:** Authentication – Registration
- **Endpoint:** POST /api/register
- **Severity:** High
- **Priority:** High
- **Input:** Valid name, email and weak password.
- **Expected:** 400 Bad Request with required-field validation messages.
- **Actual:** 500 Internal Server Error.
- **Status:** Open

**Impact:** Users submitting passwords shorter than the required 6 characters receive a generic server error instead of meaningful validation feedback.
