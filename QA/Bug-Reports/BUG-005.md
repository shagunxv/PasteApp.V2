BUG-005: Missing Name Causes Server Error

- Module: Authentication – Registration
- Endpoint: POST /api/register
- Severity: High
- Priority: High
- Input: Valid email and password, with name field missing.
- Expected: 400 Bad Request with required-name validation messages.
- Actual: 500 Internal Server Error.
- Status: Open

Impact: Users receive a server error instead of meaningful validation feedback when submitting the registration form without a name.
